Airia (Airia LLC, Atlanta) is an enterprise AI orchestration, security and governance platform: a no-code/low-code/pro-code agent builder, a model routing and cost gateway, an MCP Gateway that fronts 1,000+ app connectors and turns hosted OpenAPI specs and Agent Skills repositories into governed MCP tools, plus AI discovery (shadow-AI inventory), red teaming, guardrails, risk registry and use-case governance. The platform is driven by the Airia Web APIs at api.airia.ai (OpenAPI 3.0, 1,299 operations, X-API-Key auth), a Python SDK on PyPI, and a remote OAuth-protected MCP Gateway at mcp-gateway.airia.ai.

**Areas:** Company · Enterprise AI · AI Agents · AI Governance · AI Security · MCP · MCP Gateway · Agent Orchestration · LLM Gateway · AI Discovery · Red Teaming · Guardrails

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Airia: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
